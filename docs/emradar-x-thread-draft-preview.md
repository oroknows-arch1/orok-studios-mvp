# Full-scan X draft and preview

`draftFullScanThread` creates a **deterministic initial draft** from every record in a published scan. It does not invent titles, statuses or evidence; missing values remain explicit. `previewThreadHtml` escapes all discovery text for an inert local preview. The generated HTML is not yet mounted in the existing owner review.

This draft is **not editorially ready for automatic release**. Before approval or posting, add record-schema-aware causal-chain writing, source fact checks, source URL verification, platform text limits, visual assets per approved post, a durable approval UI, and the separate thread reservation/publisher. No change has been made to production V3. Grok remains research-only.
