## Automatic V3 feasibility

**Supported in principle, no live API proof.** Google documents a server-side Gemini Interactions call with Google Search grounding and JSON Schema output on supported model families. Google Search AI Mode itself was exercised in a connected browser. It returned no answer on the full payload and gave a different best-effort response on a compact prompt. Those observations do not establish an unattended browser interface with stable authentication, response structure, costs or total coverage. No configured Gemini credentials were available here. No live API request, billing setup or production integration occurred. [Grounding docs](https://ai.google.dev/gemini-api/docs/google-search) · [Structured output with tools](https://ai.google.dev/gemini-api/docs/structured-output#tools) · [Google pricing](https://ai.google.dev/gemini-api/docs/pricing) · [Data and grounding terms](https://ai.google.dev/gemini-api/terms)

**Local test.** Run `node --test experiments/whole-campaign-audit-shadow.test.mjs`. Three tests passed using a simulated Google transport: one structured request covers all 16 while excluding contact/approval fields; incomplete, duplicate, unknown-ID and malformed outputs are rejected; an unavailable provider returns without mutating the campaign or retrying. This proves the V3-side boundary can be implemented; it does not check provider authentication, response envelopes, latency, costs or source quality. A real test should use credentials already authorised for the appropriate data tier and an approved budget. Google’s unpaid-service terms say confidential information must be excluded. Keep recipient contact data, tokens and owner state out of any provider packet, and keep usage/grounding records with the advisory response.

**What can become lighter.** One optional campaign-wide pass could replace repeated overlap, outlet-fit and copy-edit opinions if a measured shadow trial shows equal or better catches across multiple campaigns. Let a simple local subject/body comparison flag exact matches at no API cost. Keep direct primary-source retrieval, interpretation of claim evidence against final wording, verified contacts, signed intake, owner approvals and distribution controls in V3. A missing, invalid or slow advisory response must leave the ordinary review flow available. Bind results to campaign and asset fingerprints and ignore stale results. Based on this run, eliminating the factual checks would pass unsupported assumptions such as common grid access, a blanket newsroom policy and the misstated Cabinet Secretariat date.
